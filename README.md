# Testeapk

Este projeto contém uma tela de login simples feita em Android.

## Como baixar o projeto

- Se estiver hospedado no GitHub/GitLab, use o botão **Code > Download ZIP**.
- Ou clone via Git: `git clone <URL_DO_REPOSITORIO>`.

## Como gerar o APK localmente

1. Abra o projeto no Android Studio.
2. Aguarde o Gradle sincronizar.
3. Vá em **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. O APK gerado ficará em `app/build/outputs/apk/debug/app-debug.apk`.

> Observação: não é possível disponibilizar um link de download direto neste ambiente.
